# Security Policy

## Reporting a Vulnerability

Please email **security@ahutgupta.dev** with:
- A clear description of the issue and impact
- Steps to reproduce or proof-of-concept
- Affected configuration (compose file, OS/Docker version)

### Response Process
- We will acknowledge reports within **2 business days**
- We aim to provide a remediation plan or fix within **10 business days** for critical issues
- Please **do not open public issues** for potential vulnerabilities

### Scope
- Supported branch: `Main`
- Preferred fix path: private coordination → patched release → public disclosure

Thank you for helping keep the project secure and safe for self-hosters.
