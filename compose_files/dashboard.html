🔐 Security Notes

  • Local Access: All ports are open on your network for easy access from any device at home
  • Tailscale Access: Only nginx routes are available, providing controlled access via VPN
  • Internet: No direct internet access - only through Tailscale VPN
  • Recommendation: Keep your WiFi password secure and use Tailscale for remote access
