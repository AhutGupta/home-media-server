🌐 Accessing Your Server

Two Ways to Access

  • Hostname: http://media-server/ - Works on local WiFi and via Tailscale
  • IP Address: Use your server's IP (Tailscale or local network)
  • All nginx-proxied services use same base URL: /view/, /music/, etc.
  • Direct ports add port number: :8080, :9696, etc.

Remote Access (via Tailscale)

  • Install Tailscale on your device (phone, laptop, tablet)
  • Sign in with the same account you used on the server
  • Use http://media-server/ or your Tailscale IP
  • No port forwarding needed - secure VPN tunnel!

What is nginx Doing?

nginx is your smart gateway that:

  • ✅ Routes all services through a single port (80)
  • ✅ Adds security headers to protect against attacks
  • ✅ Enables WebSocket support for real-time features
  • ✅ Provides this beautiful dashboard you're seeing!
  • ✅ Can add SSL/HTTPS, caching, rate limiting, and more

💡 Quick Tips

  • First Time Setup: Visit each service to create admin accounts
  • Security: Change default passwords immediately (especially qBittorrent!)
  • Storage: All media is stored on your E: and F: drives
  • Downloads: qBittorrent saves to configured download folders
  • Automation: Sonarr/Radarr automatically manage downloads
  • Updates: Run docker-compose pull && docker-compose up -d
