🏠 Home Media Server

All services accessible via direct ports

📍 How to Access Services

Use direct port access - these work from everywhere:

From Server Machine: localhost:8096
From WiFi Network: media-server:8096
Via Tailscale VPN: 100.x.x.x:8096

Replace 8096 with the port number of the service you want to access.
